# Kıble — belgeler

[Kıble](https://github.com/mertxsenturk/kible) uygulamasının gizlilik
politikası, kullanım koşulları ve destek sayfası. GitHub Pages ile
yayımlanır.

Bu depo yalnızca bu belgeler için **herkese açıktır**; uygulamanın kaynak
kodu ayrı ve özel bir depoda durur. Sebep: GitHub Pages ücretsiz hesaplarda
yalnızca açık depolarda çalışıyor, ama kodun açılması gerekmiyordu.

## Düzenlerken

Metinler uygulamanın gerçek davranışına göre yazıldı. Uygulamanın veri
davranışı değişirse — özellikle dışarıya istek atan bir şey eklenirse —
gizlilik politikasındaki tablo da güncellenmeli. Şu an cihazdan veri çıkan
üç yer var: Overpass (yakındaki camiler), Apple coğrafi kodlama (şehir
arama), Apple (satın alma).

Yürürlük tarihini değiştirmeyi unutma.
